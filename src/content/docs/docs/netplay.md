---
title: "Netplay"
description: "Play multiplayer games online."
---

**Main Menu** → **System Settings** → **Netplay Settings**

Turn **Enable netplay** on and set a **Nickname**. **Use relay server** helps when your router blocks incoming connections; pick the server closest to you.

## RetroArch games

With netplay on, RetroArch-based systems can host and join games. Every player needs the same game file and the same core.

## PlayStation (Riverhorse)

Riverhorse has its own rollback netplay for two players plus spectators. Host or join from Riverhorse's in-game panel. All players get the host's settings and BIOS.
