PC handhelds use the normal **PC** image. Write it to a USB drive or a microSD card, boot from it, and [install to the internal drive](/docs/installation/#4-install-to-an-internal-disk-pc-optional) once you're happy.

## Built-in controls

The built-in controller is set up automatically by InputPlumber, so it works like a normal pad in EmulationStation and in games.

**Main Menu** → **Controller & Bluetooth Settings** → **Handheld Controller Settings**

- **Controller type**: what the built-in controls appear as to games (for example an Xbox or DualSense pad).
- **Button mapping**: the button layout profile.

## Power and performance

On AMD handhelds HippOS controls the power limit (TDP). Set it for all games, a system or one game in **Advanced Game Options** (hold **A** on a game), along with the power mode. Lower limits run cooler and last longer on battery; higher limits help demanding systems such as PS2, GameCube and Switch.

## Screen

Brightness and volume work from the hotkeys. Portrait-mounted screens are rotated automatically; if yours isn't, set **Main Menu** → **System Settings** → **Screen Rotation**.

## Help

Handheld support changes the most between releases. Ask in **#pc-handhelds** on the [Discord](https://hippos-linux.org/discord) with your exact model.
