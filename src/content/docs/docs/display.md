---
title: "Display & Resolution"
description: "Resolution, rotation, multiple screens, shaders and CRT output."
---

HippOS starts at 1080p60 where the display supports it and follows displays being plugged in or out.

## Resolution

- **EmulationStation**: **Main Menu** → **System Settings** → **Video Mode**
- **Games**: **Main Menu** → **Game Settings** → **Video Mode**

## Screen rotation and brightness

**Main Menu** → **System Settings** → **Screen Rotation** / **Brightness**

## More than one screen

**Main Menu** → **System Settings** → **Video Output** picks the screen EmulationStation uses. **Multiscreens** sets up extra screens.

## Shaders and aspect ratio

**Main Menu** → **Game Settings** for all games, or per system and per game from a game's **Advanced Game Options** (hold **A** on a game).

## CRT

CRT output is supported through Switchres, with modelines generated automatically. It's off by default:

**Main Menu** → **System Settings** → **CRT Monitor**

## Audio over HDMI

**Main Menu** → **System Settings** → **Audio Output**
