Xbox, PlayStation, Switch Pro and most generic USB and Bluetooth pads work out of the box. Xbox wireless pads use the xpadneo and xone drivers.

## Mapping

**Main Menu** → **Controller & Bluetooth Settings** → **Controller Mapping**

Hold a button on the pad you want to map, then follow the prompts. The button you map as **Hotkey** is used for the shortcuts below; on most pads it's the Guide / PS / Home button.

## Bluetooth

**Main Menu** → **Controller & Bluetooth Settings**

- **Pair Bluetooth pads automatically**: put the pad in pairing mode and HippOS pairs it.
- **Pair a Bluetooth device**: pick it from a list.

Paired pads reconnect by themselves.

## Hotkeys

Hold **Hotkey** and press:

| Button | In a game |
|---|---|
| **Start** | Exit back to EmulationStation |
| **A** | Quick menu |
| **B** | Emulator menu |
| **Y** / **X** | Save state / load state |
| **Up** / **Down** | Next / previous state slot |
| **Left** / **Right** | Rewind / fast forward |
| **L1** | Screenshot |
| **R1** | Translation |
| **L2** / **R2** | Swap screens / change screen layout (dual-screen systems) |
| **L3** | Next disc |

These work the same in every emulator that supports the action, not just RetroArch.

## Handhelds

On PC handhelds and RK3326 handhelds the built-in controls are set up automatically.

**Main Menu** → **Controller & Bluetooth Settings** → **Handheld Controller Settings**

## Players

**Main Menu** → **Controller & Bluetooth Settings** → **Controllers Priority** sets which pad is player 1, 2, and so on.

## On-screen keyboard

In desktop mode and in apps launched from EmulationStation, an on-screen keyboard opens when a text field is selected. Use the d-pad to move, **A** to type, **B** to close, **L1** to delete, **R1** for space and **Start** to finish.
