Press **Start** in EmulationStation to open the **Main Menu**.

| Menu | What's in it |
|---|---|
| **Netplay Lobby** | Join or host online games and chat (shown when netplay is on) |
| **Game Settings** | Defaults for all games: video mode, shaders, aspect ratio, rewind, Update Gamelists, RetroAchievements and netplay settings |
| **Controller & Bluetooth Settings** | Mapping, Bluetooth pairing, player order, handheld controls |
| **User Interface Settings** | Theme, screensaver, game list layout |
| **Game Collection Settings** | Automatic and custom collections |
| **Sound Settings** | Volume and sounds |
| **Network Settings** | Wi-Fi, hostname, IP address |
| **Scraper** | Download box art, videos and game information |
| **Updates & Downloads** | System and emulator updates, the content store, themes |
| **System Settings** | Information, language, time zone, display, audio output, storage, BIOS check |
| **Select Desktop** | Switch to the desktop |

## Per system and per game

Most game settings can be set for one system or one game. Hold **A** on a game → **Advanced Game Options**, or press **Select** on a system.

## Version

**Main Menu** → **System Settings** → **Information**

## RetroAchievements

**Main Menu** → **System Settings** → **RetroAchievement Settings**, then sign in with your [RetroAchievements](https://retroachievements.org) account.

## Desktop mode

**Main Menu** → **Select Desktop** switches to a full desktop (LXQt by default) for browsing files, installing apps or using a web browser. To come back, use the **Switch to ES** shortcut on the desktop.

## Store

**Main Menu** → **Updates & Downloads** → **Content Downloader** installs apps, ports, shaders and more, and can search Flathub and Debian.

## Config files

Emulator and system settings are in `/userdata/system/configs/`. You can edit them over the network share, but the menus cover most things.
