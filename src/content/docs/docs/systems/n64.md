## About

Nintendo's first 3D console, released in Japan in June 1996, with cartridges and the first analog stick on a Nintendo controller. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with RetroArch as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/n64/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Game Formats Explained

- **.7z**: 7-Zip archive; works like .zip but is slower to open.
- **.zip**: Zip archive. Most cartridge systems and arcade sets can be played zipped.


## Formats

`.z64`, `.n64` and `.v64` are the same game in different byte orders; all of them work. Zipped games work too. No BIOS is needed; the 64DD add-on has its own [page](/docs/systems/n64dd/).
