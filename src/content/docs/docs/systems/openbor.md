## About

On HippOS, OpenBOR runs on PC, Raspberry Pi and RK3326 handhelds, with OpenBOR as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/openbor/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
