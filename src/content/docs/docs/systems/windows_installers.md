## About

On HippOS, Windows Installers runs on PC, Raspberry Pi and RK3326 handhelds, with Wine as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/windows_installers/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Emulators

| Emulator (★ default) | About | PC | Pi / RK3326 |
|---|---|:-:|:-:|
| **[Wine](https://www.winehq.org/)** | Runs Windows games on Linux.<br><small>**Formats:** all · **BIOS:** none</small> | ★ | ★ |

## Game Formats Explained

- **.exe**: Windows or DOS program.
- **.iso**: Uncompressed disc image.
