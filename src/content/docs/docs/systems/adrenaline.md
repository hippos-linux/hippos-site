## About

The Adrenaline Amusements is an arcade system by Adrenaline Amusements. On HippOS it runs on PC, with Windows Arcade Loader as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/adrenaline/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Game Formats Explained

- **.squashfs**: Compressed read-only folder image. HippOS mounts it when the game starts, so the game stays compressed on disk.
