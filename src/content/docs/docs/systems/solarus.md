## About

On HippOS, Solarus runs on PC, Raspberry Pi and RK3326 handhelds, with Solarus as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/solarus/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
