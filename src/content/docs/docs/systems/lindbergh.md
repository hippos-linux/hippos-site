## About

The Sega Lindbergh is an arcade system by Sega. On HippOS it runs on PC, with Lindbergh Loader as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/lindbergh/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
