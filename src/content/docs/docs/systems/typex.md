## About

The Taito Type X is an arcade system by Taito. On HippOS it runs on PC, with Windows Arcade Loader as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/typex/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Emulators

| Emulator (★ default) | About | PC | Pi / RK3326 |
|---|---|:-:|:-:|
| **[Windows Arcade Loader](https://github.com/aderumier/windowsarcadeloader)** | Runs PC-based arcade games (Taito Type X, NESiCA and similar).<br><small>**Formats:** all · **BIOS:** none</small> | ★ |  |

## Game Formats Explained

- **.squashfs**: Compressed read-only folder image. HippOS mounts it when the game starts, so the game stays compressed on disk.
