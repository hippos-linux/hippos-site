## About

The TIC-80 is a console. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with TIC-80 as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/tic80/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
