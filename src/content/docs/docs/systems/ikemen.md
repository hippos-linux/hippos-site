## About

On HippOS, IKEMEN runs on PC, Raspberry Pi and RK3326 handhelds, with IKEMEN GO as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/ikemen/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Emulators

| Emulator (★ default) | About | PC | Pi / RK3326 |
|---|---|:-:|:-:|
| **[IKEMEN GO](https://github.com/ikemen-engine/Ikemen-GO)** | Open-source fighting game engine compatible with M.U.G.E.N content.<br><small>**Formats:** all · **BIOS:** none</small> | ★ | ★ |

## Game Formats Explained

- **.pc**: Folder-style DOS game: a folder named `Game.pc` with the game inside.
