## About

FinalBurn Neo emulates arcade machines and some consoles, and is lighter than MAME, so it suits handhelds and the Raspberry Pi. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with RetroArch as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/fbneo/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Emulators

## Game Formats Explained

- **.7z**: 7-Zip archive; works like .zip but is slower to open.
- **.zip**: Zip archive. Most cartridge systems and arcade sets can be played zipped.


## ROM sets

Use `.zip` sets made for FinalBurn Neo. MAME sets of the same games often differ and may not load.
