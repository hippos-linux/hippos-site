## About

The Commander X16 is a computer by The 8-Bit Guy. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with x16emu as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/commanderx16/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
