## About

The Commodore 128 is a computer by Commodore. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with VICE as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/c128/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Game Formats Explained

- **.7z**: 7-Zip archive; works like .zip but is slower to open.
- **.d64**: Commodore 1541 floppy disk image.
- **.m3u**: Plain-text playlist of discs or disks; lets a multi-disc game appear once and swap discs with Hotkey + L3.
- **.zip**: Zip archive. Most cartridge systems and arcade sets can be played zipped.
