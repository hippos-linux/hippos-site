## About

The PC (86Box) is a computer by IBM. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with 86Box as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/86box/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Emulators
