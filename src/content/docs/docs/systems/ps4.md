## About

The PlayStation 4 is a console by Sony. On HippOS it runs on PC, with shadPS4 as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/ps4/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
