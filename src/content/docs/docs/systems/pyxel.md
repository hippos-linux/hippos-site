## About

The Pyxel is a console. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with Pyxel as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/pyxel/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
