## About

The N-Gage is a handheld by Nokia. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with EKA2L1 as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/ngage/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Emulators
