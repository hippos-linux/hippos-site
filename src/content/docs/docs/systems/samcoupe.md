## About

The SAM Coupé is a computer by Miles Gordon Technology. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with SimCoupe as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/samcoupe/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Game Formats Explained

- **.dsk**: Floppy disk image.
- **.zip**: Zip archive. Most cartridge systems and arcade sets can be played zipped.
