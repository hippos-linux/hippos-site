## About

The Namco System 246/256 is an arcade system by Sony / Namco. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with PCSX2 x6 as the default on PC and Play! on Raspberry Pi and RK3326.

## Getting ROMs

Put your files in `/userdata/roms/namco2x6/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
