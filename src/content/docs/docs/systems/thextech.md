## About

On HippOS, TheXTech runs on PC, Raspberry Pi and RK3326 handhelds, with TheXTech as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/thextech/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Emulators

| Emulator (★ default) | About | PC | Pi / RK3326 |
|---|---|:-:|:-:|
| **[TheXTech](https://github.com/Wohlstand/TheXTech)** | Engine for Super Mario Bros. X and its episodes.<br><small>**Formats:** all · **BIOS:** none</small> | ★ | ★ |

## Game Formats Explained

- **.squashfs**: Compressed read-only folder image. HippOS mounts it when the game starts, so the game stays compressed on disk.
