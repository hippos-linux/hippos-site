## About

The Visual Pinball X is a pinball system by Randy Davis. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with Visual Pinball X as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/vpinball/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
