## About

The Model 2 is an arcade system by Sega. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with Keisho as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/model2/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.
