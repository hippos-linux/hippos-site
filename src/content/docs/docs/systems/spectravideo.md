## About

The Spectravideo SV-328 is a computer by Spectravideo. On HippOS it runs on PC, Raspberry Pi and RK3326 handhelds, with openMSX as the default emulator.

## Getting ROMs

Put your files in `/userdata/roms/spectravideo/`. See [Adding ROMs](/docs/adding-roms/) for ways to copy them to HippOS.

After adding games: **Main Menu** → **Game Settings** → **Update Gamelists**.

## Emulators

| Emulator (★ default) | About | PC | Pi / RK3326 |
|---|---|:-:|:-:|
| **[openMSX](https://openmsx.org/)** | Accurate MSX, MSX2, MSX2+ and turbo R emulator.<br><small>**Formats:** all · **BIOS:** none</small> | ★ | ★ |
| **[RetroArch](https://www.retroarch.com/)** | Frontend for libretro cores, with shaders, rewind, netplay and RetroAchievements. Cores: `bluemsx`, `openmsx`.<br><small>**Formats:** all · **BIOS:** none</small> | ✔ | ✔ |

## Game Formats Explained

- **.7z**: 7-Zip archive; works like .zip but is slower to open.
- **.zip**: Zip archive. Most cartridge systems and arcade sets can be played zipped.
