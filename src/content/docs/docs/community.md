## Discord

**[Join the HippOS Discord](https://hippos-linux.org/discord)**

| Where | For |
|---|---|
| **Support** forums (PC, PC handhelds, Raspberry Pi, RK3326, EmulationStation, general help) | Help with your setup |
| **#quick-help** | One-line questions |
| **#bug-reports** | Something is broken |
| **#suggestions** | Ideas for HippOS |
| **#handheld-requests** | Devices you'd like supported |
| **Riverhorse** | HippOS's own PS1 emulator |
| **#announcements** and **#update-log** | News and release notes |
