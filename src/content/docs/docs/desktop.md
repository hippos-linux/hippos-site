---
title: "Desktop mode"
description: "Switch to a full Linux desktop, and back."
---

HippOS has a full desktop for browsing files, installing apps, using a web browser or anything else EmulationStation doesn't do.

## Switching

**Main Menu** → **Select Desktop** lists the desktops: LXQt is the default and is light enough for handhelds; Xfce, MATE, Cinnamon, KDE Plasma and GNOME can be installed from the same list. Pick one to install it or switch to it.

To go back, use the **Switch to ES** shortcut on the desktop.

## With a controller

- The left stick moves the pointer, the right stick scrolls, and the face buttons click.
- An on-screen keyboard opens when a text field is selected (see [Controllers](/docs/controllers/#on-screen-keyboard)).

## Installing apps

**HippOS Store** on the desktop installs and updates apps, and shows HippOS updates too. See [the store](/docs/store/#hippos-store-on-the-desktop).

## Files

Your games and settings are in `/userdata`, which is your home folder on the desktop.

Network shares, such as a NAS, are under **Network** in the file manager. Shares that allow guests log in as `guest` with no password.

## Handhelds

On handhelds, windows open maximized so they fit above the taskbar.
