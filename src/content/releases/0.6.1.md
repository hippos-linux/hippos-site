---

### Hardware

- Realtek USB Wi-Fi dongles stuck in CD-ROM mode are now switched to network mode automatically.
- Fixed a `/dev/nvidia0` boot race on hybrid AMD + NVIDIA machines.
- Fixed a legacy NVIDIA driver module filename mismatch.
- Bluetooth no longer crash-loops on machines without Bluetooth hardware.

### Session & hotkeys

- Hotkey combos are debounced, and switching to desktop is locked while a switch is in progress.
- Steam's hotkey context now has a proper exit path.
- Mode switches between EmulationStation and desktop get a wider restart budget.

### CRT

- CRT output is only activated when explicitly enabled.
- The boot resolution is restored after an emulator exits.

### Boot & install

- Boot no longer waits on real network connectivity.
- The installer no longer re-mounts the running system's own EFI partition.
