summary: "Boot reliability, NVIDIA, and emulator packaging fixes."
---

### Boot

- Fixed a hang where the boot splash kept control of the display and EmulationStation never appeared.
- Removed the default serial console, which could stall boot on some machines.
- Waydroid's first-boot setup no longer waits for the network.

### Graphics

- NVIDIA persistence daemon now starts after GPU detection, with retries and a warning on stale kernel module metadata.

### Diagnostics

- Boot logs now include the previous boot's journal, so a crash or hang can be investigated after a reboot.
- Hard crashes leave a trace in EFI persistent storage.

### Emulators

- RPCS3 ships its own LLVM library for the recompiler backend.
- DuckStation ships its APNG-patched libpng and always uses the X11 Qt backend for game launches.
- Added more MAME and FBAlpha core variants to RetroArch.
- Emulator binaries are now stripped consistently, making downloads smaller.
